# 关于我们

## 项目简介

MDNA（皎皎二重小助手）是一个开源、免费的自动化辅助工具，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 强力驱动，通过图像识别 + 模拟操作的方式，帮助玩家简化《二重螺旋》中的重复性操作。

- 项目地址：<https://github.com/BQOvO/MDNA>
- 许可证：MIT
- 开发者：BQOvO
