# 常见问题

## 使用说明

### 模拟器设置

1. 将分辨率调整为`平板版`的 16:9 分辨率，如 `1280×720`、`1600×900` 或 `1920×1080`；性能足够时推荐使用 `1920×1080` 分辨率。
2. 使用雷电模拟器可能会出现乱点的 Bug，优先推荐使用 MuMu 模拟器。

## 通用问题

### Q1：启动提示"资源加载失败"？

1. 删除安装目录下除 `config` 外所有文件夹
2. 重新解压最新版到原目录
3. 重启软件

### Q2：我下载的是官网下的pc端可以用吗？

用不了。（pc端没有计划适配）项目目前仅支持模拟器本地游戏（暂不支持云游戏）。

### Q3：如何让脚本自动启动模拟器？

1. 在软件下方点击添加任务 → 特殊任务 → 前置程序
2. 填入模拟器路径，附加参数为所需模拟器序号的 n-1（例如你是 MuMu 模拟器第二台，参数就是 `-v 1`）
3. 推荐再加一个倒计时任务

## 连接问题

### Q1：连接后无响应？

检查清单：

- 模拟器分辨率设为 16:9
- 重启模拟器 + 软件
- 软件内执行"连接测试"
- 优先使用 MuMu/雷电模拟器

### Q2：能识别但是不能点击？

目前在 MuMu V5 的个别版本发现这个情况，原因不明，可以更新或者回退版本。

## 下载问题

### Q1：下载速度特别慢怎么办？

若从 GitHub 源下载速度较慢，可搜索相关加速教程，或加入MDNA QQ 群（1002051753）
#### 技术支持

### Q1：如何导出有效日志？

1. 删除 `debug` 文件夹
2. 复现问题
3. 点击软件内 **|→** 按钮导出日志
4. 连同截图提交至 [GitHub Issues](https://github.com/BQOvO/MDNA/issues)

### Q2：双击无法启动，命令行可运行？

Windows 安全策略解除：右键 `MDNA.exe` → 属性 → 勾选"解除锁定" → 应用

## 常用技巧

1. 第一次启动会有教程，可以跟着看完。同时公告和教程也可以在设置 → 关于我们处重新唤起，也可以在同样的地方导出。
2. 右键任务可以单独运行任务或者运行该任务及后续任务。
3. 可以重置任务、添加任务（包括定时、通知等功能）等形成自己的配置。
4. 可以添加配置达成运行不同任务流等功能，也可以试着靠这个多开。
5. 可以复制 `config` 文件夹到新的 MDNA 以此保存设置，但是并不保证一定可以适配新版本。
